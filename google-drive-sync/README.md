# Google Drive Sync (Google Apps Script)

আপনার অ্যাপের ডেটা আপনার নিজের **Google Drive**-এ একটি ফাইলে (`BMS_Sync_Data.json`) জমা রাখার ব্যাকএন্ড। কোনো সার্ভার বা খরচ লাগে না।

> ⚠️ **কেন আগের URL কাজ করেনি:** অ্যাপ আগে শুধু `server/` ফোল্ডারের Node সার্ভারের সাথে কথা বলত (`/api/push`, `/api/pull`, Socket.IO)। একটি খালি/অন্য উদ্দেশ্যের Apps Script URL সেই ভাষা বোঝে না। এই ফোল্ডারের `Code.gs` হলো সেই অনুবাদক, আর অ্যাপ (v3.1) এখন `script.google.com` URL নিজে চিনে নেয়।

## সেটআপ (একবারই, ~৫ মিনিট)

1. [script.google.com](https://script.google.com) → **New project**।
2. ডিফল্ট কোড মুছে `Code.gs`-এর পুরো লেখা পেস্ট করুন।
3. ওপরের দিকে `API_KEY` লাইনে `CHANGE_ME_...` বদলে নিজের একটি লম্বা গোপন পাসওয়ার্ড দিন (যেমন ২৪+ অক্ষরের র‍্যান্ডম লেখা)। Save (Ctrl+S)।
4. ওপরের ফাংশন-ড্রপডাউন থেকে **`setup`** সিলেক্ট করে **Run** চাপুন। Google অনুমতি চাইবে (Drive অ্যাক্সেস) → *Review permissions* → আপনার অ্যাকাউন্ট → *Advanced* → *Go to project (unsafe)* → *Allow*। এতে Drive-এ `BMS_Sync_Data.json` ফাইল তৈরি হবে।
5. **Deploy → New deployment → ⚙ Select type → Web app**
   - **Execute as:** Me
   - **Who has access:** **Anyone** ← এটা না দিলে অ্যাপ অ্যাক্সেস পাবে না
   - **Deploy** চাপুন → যে **Web app URL** (শেষে `/exec`) পাবেন সেটি কপি করুন।
6. ব্রাউজারে ওই URL খুলুন। এই লেখা দেখলে সব ঠিক: `{"ok":true,"message":"BMS Drive sync is running",...}`
7. অ্যাপে Super Admin → **Building Settings → Sync/API**:
   - **API Endpoint URL:** ওই `/exec` URL
   - **API Key:** ধাপ ৩-এ দেওয়া একই পাসওয়ার্ড
   - Save।

## অন্য ডিভাইস যোগ করা (গুরুত্বপূর্ণ)

প্রতিটি ডিভাইস প্রথমবার চালু হলে নিজে ডেমো ডেটা (admin ইউজার, ডেমো ফ্ল্যাট ইত্যাদি) বানায়, যার আইডি প্রতি ডিভাইসে আলাদা। দুই ডিভাইসে আলাদাভাবে শুরু করে পরে সিঙ্ক চালু করলে ডুপ্লিকেট/সংঘর্ষ হবে। তাই:

1. **মূল ডিভাইসে** আগে সিঙ্ক চালু করুন।
2. মূল ডিভাইসে **Settings → Backup & Restore → Download Backup**।
3. **অন্য ডিভাইসে** ব্যাকআপটি **Restore** করুন (এতে সব রেকর্ড একই আইডিসহ আসে)।
4. তারপর সেই ডিভাইসেও Sync/API-তে একই URL + Key দিন।

## জানা সীমাবদ্ধতা

- Google Apps Script-এ WebSocket নেই, তাই এখানে সিঙ্ক **রিয়েল-টাইম নয়, প্রায় ১ মিনিটের মধ্যে**। নিজের পরিবর্তন সাথে সাথে আপলোড হয়; অন্য ডিভাইসের পরিবর্তন প্রায় প্রতি ৬০ সেকেন্ডে, অথবা ট্যাবে ফিরে এলেই নেওয়া হয়। (সত্যিকারের রিয়েল-টাইম চাইলে `server/` ফোল্ডারের Node সার্ভার ব্যবহার করুন।)
- Google-এর দৈনিক স্ক্রিপ্ট-রানটাইম কোটা আছে; ছোট একটি ভবনের জন্য যথেষ্ট, তাই পোলিং ১ মিনিটে রাখা হয়েছে।
- API Key পোল করার সময় URL-এর অংশ হিসেবে যায় (HTTPS-এ এনক্রিপ্টেড), তবে এটি সাধারণ সুরক্ষা — অত্যন্ত সংবেদনশীল ডেটার জন্য নিজের সার্ভার ভালো।
- **`Code.gs` পরে বদলালে** Deploy → Manage deployments → ✏ Edit → Version: **New version** → Deploy করতে হবে, নাহলে পুরনো কোড চলতে থাকবে।
- ব্যাকআপ হিসেবে Drive ফাইলের ভার্সন-হিস্ট্রি (File → Version history) কাজে লাগে।

## সমস্যা হলে

| লক্ষণ | কারণ |
|---|---|
| অ্যাপে "Unauthorized" / ডেটা যাচ্ছে না | অ্যাপের API Key আর `Code.gs`-এর `API_KEY` মেলেনি, অথবা Key বদলানোর পর নতুন ভার্সন ডিপ্লয় করা হয়নি |
| ব্রাউজারে URL খুললে লগইন পেজ আসে | "Who has access" = **Anyone** দেওয়া হয়নি |
| ব্রাউজারে URL খুললে 404 | ভুল URL (অবশ্যই `.../exec` দিয়ে শেষ), বা ডিপ্লয়মেন্ট মুছে গেছে |
| কনসোলে CORS এরর | URL `/dev` দিয়ে শেষ — `/exec` ব্যবহার করুন |
